## 本轮验收与实施

1. 需求技能：当前规范原位更新；固定入口；有效其他范围另行归属；保护未提交内容；不自动推送或代签采用。插件独立验证、提交与安装。
2. KIOSK-1：在已存在的 draft/KIOSK-1 工作树，以我方 PRD 替换主 prd.md；整体规则保留为 system-requirements.md 参考；移除主文档的历史复核流水，保留全部 AC-01 至 AC-29 和七项外部契约占位；修正引用。本地提交，不自动推送、采用或重跑真实 WBS。
3. WBS：新运行只读登记范围中唯一的 prd.md，目录展开为直接子文件 prd.md；不递归扫描或猜测其他名称，多候选/缺失报错。无文档的工作项正文流程保留。记录输入策略与固定 SHA。
4. 既有验收范围不变：新 WBS 的主文档必须与完整验收快照中的同路径内容及已采用版本一致；历史运行仍按原输入规则核验，不改写历史数据。
5. 无有效旧基线或入口范围变化时不生成全文新增差异；旧结果只作对比，不扩大当前主 PRD 的交付范围。

## 验证

先增加回归，证明目录扫描、歧义选择和首次全文重复问题；再修改 wbs_update.py。回归覆盖唯一主文件、缺失/歧义、SHA 不匹配、完整验收与主文件子集匹配、版本变化拦截、历史兼容与已有 WBS 测试。隔离数据库运行，不操作生产任务。代码检查通过后本地提交。

本轮不调整业务授权规则、网络、模型、超时参数、前端，不部署正式服务。实际线上最小输入需后续部署及新文档推送/采用；现有已采用 SHA 不等于本次本地版本。
