## 静态候选清单

运行 `pnpm --filter @plane/i18n exec tsx scripts/audit-user-text.ts` 生成 [english-candidates.json](./english-candidates.json)。条目包含文件、行号、类别与原文，可用于定位后续验收单元。

本轮扫描：主站 1699、后台 259、分享页 89、编辑器 106、共享组件 11 条候选。这些不是确定漏译数量，包含品牌、技术标识和翻译键，必须人工分类；也不包含所有动态文案、后端及邮件内容。不可据此自动翻译用户数据或宣称零遗漏。

## 重复验证

```powershell
pnpm --filter @plane/i18n test
pnpm --filter @plane/i18n build
pnpm --filter @plane/services test
pnpm --filter @plane/editor test
pnpm --filter admin check:types
docker compose -f docker-compose-test.yml run --rm api-tests pytest plane/tests/unit/models/test_profile_language.py plane/tests/unit/middleware/test_language.py plane/tests/unit/utils/test_localized_email.py -q
```

修改词库/语言/命名空间后运行 i18n 构建以重新生成静态导入清单。`src/load-locale.ts` 由 `scripts/generate-loader.ts` 生成，不应手工编辑。

Django 中文目录位于 `apps/api/plane/locale/zh_Hans/LC_MESSAGES`。同时提交 `.po` 与 `.mo`，生产镜像已有的 `COPY plane/ plane/` 会包含编译结果。在安装 GNU gettext 的开发环境运行 `python manage.py compilemessages -l zh_Hans` 后重新运行邮件测试。当前没有增加运行时 Python 依赖。
