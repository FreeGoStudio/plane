# 文档审查反馈可读性

2026-11-25，依据用户对 SING-19 F1/F2 反馈难读的反馈，优化表达和页面层级。
不修改阻断级别、审查判定、引用校验、人工采用或合并规则。

- 新报告生成简短 `title`，理由先说明问题再说明验收影响，多个修改动作使用列表。
- 历史报告可缺少标题，页面使用理由首句摘录，不重写已保存报告或改变其摘要哈希。
- 问题卡片显示编号、级别、标题和位置；展开后分为“问题与影响”和“建议修改”。
- 引用原文独立折叠且逐字保留。说明文字支持安全的 Markdown 段落、换行、列表和强调，
  不启用原始 HTML、链接或远程媒体。
- 三项新增界面文案同步到全部22种语言，中文提供对应文案，其他语言沿用英文占位约定。

格式和差异检查通过。新增标签在22种语言中完整；全站同步检查仍报告其他语言既有1277项缺失。

预览未操作线上审查、采用或重试；测试数据中的原文未改写。

简短标题和新的表达约束适用于之后生成的报告，无需修改或重跑旧报告。
