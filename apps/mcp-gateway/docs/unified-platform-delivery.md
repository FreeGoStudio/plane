## 固定边界

- Plane 用户为主身份；MCP 只读取 HTTP 授权头，不采用 ChatGPT 账号或模型自报身份。
- 公司 GitLab 单点登录与仓库个人凭证分开；自动开户不自动授予仓库权限。
- 项目支持多个仓库及托管实例；凭据只供所有者使用，不借用管理员或其他成员凭据。
- 不实现仓库写入、自动编码/合并、SSH 登录、成员权限同步、自动归档及共享 Worker。
- 不开放公网，不更改既有用户密码，不批量为旧用户开户，不迁移既有登录 Token。
- 每个验收单元分别记录实现、自动测试、真实验收；仅提交本任务修改。

## 本轮 P1：个人令牌

原始验收依据：计划要求同时支持 OAuth 与受限个人访问令牌，默认 30 天、最长 90 天、只显示一次、单独撤销；委托令牌期限不得扩大。

已有证据：授权连接、摘要存储、受众交换和撤销均可复用；现有实现没有个人令牌签发入口，交换固定签发 5 分钟可能超出源令牌剩余期限。

本轮修改：新增受 CSRF 和个人登录保护的创建页面，显式选择范围，复用授权撤销；交换有效期限制为源令牌到期时间与 5 分钟的较小值。

未做：OIDC、GitLab 开户、多仓库、正式部署和真实客户端个人令牌验收；不得将本单元通过标记为整份计划完成。

验证结果：隔离 PostgreSQL 测试环境中，8 项个人令牌测试和 20 项既有 OAuth/MCP 回归全部通过（28 passed）；Ruff 检查通过。创建、摘要存储、范围和有效期限制、跨用户撤销无效、本人撤销立即生效、CSRF 阻止签发、Bot 拒绝、委托到期上限均已验证。尚未做浏览器及真实客户端个人令牌验收，未部署。

关联发现（仅登记）：Plane 既有 CSRF 拒绝页面使用 HTTP 200；测试通过检查拒绝模板与数据库没有产生令牌验证请求确实被拒绝，本任务没有改动通用登录行为。本机 uv 0.12.5 不满足仓库要求 0.12.21，测试与 lint 使用项目 Docker 测试环境完成。
